# Prevention and Awareness Recommendations

## Individual Users

1. Do not click unexpected links in emails.
2. Verify the sender before responding.
3. Do not execute unexpected executable attachments.
4. Use multi-factor authentication.
5. Report suspicious emails immediately.
6. Verify financial transactions independently.

## Organizations

1. Deploy SPF, DKIM and DMARC.
2. Provide regular phishing-awareness training.
3. Use multi-factor authentication.
4. Monitor unusual login activity.
5. Maintain centralized security logs.
6. Establish an incident-response procedure.
7. Restrict execution of unknown file types.

## Financial Security

1. Enable transaction alerts.
2. Monitor unusual transfers.
3. Implement fraud-detection systems.
4. Establish rapid reporting procedures for suspected fraud.

## Policy and Awareness

Cybersecurity awareness programs should teach users how to
identify phishing, spoofing, suspicious attachments and fraudulent
payment requests.
