# Financial Fraud Analysis

## Case

Operation Hydra

## Objective

The purpose of this analysis is to trace the simulated movement
of funds following the phishing-based financial fraud.

## Initial Fraudulent Transaction

Transaction TXN001 represents the initial simulated fraudulent
transfer.

Victim Account → Virtual Mule Account M001

Amount: INR 48,500

## Subsequent Fund Movement

The funds received by M001 were divided into two simulated
transfers.

### Transaction TXN002

M001 → Virtual Wallet W001

Amount: INR 45,000

### Transaction TXN003

M001 → Virtual Account M002

Amount: INR 2,500

## Investigation Findings

The transaction sequence demonstrates a simulated layering
pattern in which funds received by the mule account are quickly
transferred to additional destinations.

The virtual crypto wallet is entirely fictional and is used only
to demonstrate the concept of tracing cryptocurrency-related
fund movements.

## Conclusion

The simulated transaction logs allow investigators to establish
a chronological money trail from the victim account to the mule
account and subsequently to additional destinations.
