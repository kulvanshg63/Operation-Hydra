# Operation Hydra: Cyber Crime Investigation

## Assignment

Cyber Crime Investigation and Digital Forensics  
Assignment 2 – Unit 2: Types of Cyber Crimes

## Case Title

Operation Hydra: Unraveling a Multi-Vector Cyber Crime Involving Phishing, Spoofing & Financial Fraud

## Objective

This project presents a simulated cyber-crime investigation involving multiple attack vectors including phishing, spoofing, unauthorized access, malware delivery, and financial fraud.

## Disclaimer

This is a simulated educational investigation. All domains, IP addresses, accounts, transactions, malware indicators, and other artifacts used in this project are fictional or documentation-only examples.

## Investigation Areas

1. Cybercrime classification
2. Phishing investigation
3. Email spoofing analysis
4. Malware behavior analysis
5. Indicator of Compromise (IOC) identification
6. Financial fraud tracing
7. Legal and ethical analysis
8. Digital evidence documentation
9. Malware/Trojan payload analysis
10. Financial transaction tracing

## Repository Structure

- `evidence/` – Simulated investigation evidence
- `analysis/` – Analysis of collected evidence
- `scripts/` – Investigation and analysis scripts
- `report/` – Final investigation report
- `screenshots/` – Screenshots of tools and analysis
- `tools/` – Tools, commands and usage notes
